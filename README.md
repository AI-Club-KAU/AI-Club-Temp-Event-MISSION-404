# MISSION 404 | المهمة الأخيرة

لعبة تفاعلية لنادي الذكاء الاصطناعي. الواجهة React مع TypeScript، والخادم Google Apps Script، والنتائج في Google Sheets.

> ⚠️ لا ترفعي ملف `Code.gs` (كود الخادم) إلى هذا المستودع، لأن فيه الإجابات الصحيحة. مكانه محرر Apps Script فقط.

## ١. ربط الموقع بالخادم

افتحي `src/config.ts` واستبدلي `PASTE_YOUR_EXEC_URL_HERE` برابط Apps Script الذي ينتهي بـ `/exec`:

```ts
export const API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

## ٢. الرفع إلى GitHub

1. أنشئي مستودعًا جديدًا عامًا (Public) باسم `mission-404`.
2. اختاري **uploading an existing file** وارفعي **محتوى** هذا المجلد كله.
   - المجلد `.github` مخفي في بعض الأجهزة. تأكدي أنه رُفع، فبدونه لا يُنشر الموقع.
3. اضغطي **Commit changes**.

## ٣. تفعيل النشر

1. في المستودع: **Settings ← Pages**.
2. في **Source** اختاري **GitHub Actions**.
3. اذهبي إلى تبويب **Actions** وانتظري حتى تظهر علامة ✓ خضراء (دقيقة تقريبًا).
4. رابط الموقع: `https://<اسم-حسابك>.github.io/mission-404/`

أي تعديل ترفعينه لاحقًا يُنشر تلقائيًا بالطريقة نفسها.

## الشعار

ضعي ملف الشعار في `public/logo.svg` (أو PNG بعد تغيير الاسم في `src/screens.tsx`). إذا لم يوجد، يظهر اسم النادي نصًا.

## تعديل الألوان

كل الألوان في أول ملف `src/theme.css`.

| المتغير | الاستخدام |
| --- | --- |
| `--paper` | الخلفية |
| `--panel` | البطاقات |
| `--signal` | الأزرار والعناصر القابلة للضغط |
| `--restored` | الإجابة الصحيحة والوحدة المستعادة |
| `--fault` | الإجابة الخاطئة والأخطاء |

## يوم الفعالية (من محرر Apps Script)

| متى | الدالة |
| --- | --- |
| قبل البدء | `resetTestData` لمسح التجارب، ثم `openEvent` |
| بعد الانتهاء | `closeEvent` لتثبيت المراكز والألقاب |

لإخفاء اسم غير لائق من اللوحة: اكتبي `hidden` في عمود `flag` لصاحبه في الشيت.
